# SiteSpecCalc

Visual jobsite calculators for concrete slabs, wire size, stair stringers, and roof rafters. Preset pages ship with the repository and also load from Supabase when the public env vars are set.

```bash
npm run dev
npm run build
npm run seed:seo
```

`seed:seo` is an offline OpenAI batch script. The site never calls OpenAI when a visitor uses a calculator.

Canonical site: https://sitespeccalc.com
